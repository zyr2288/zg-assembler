# 插件配置

插件的配置，在原本的 `project-setting.json` 下加入 `plugin` 选项，比如 `ExportMesen2Label`。

```json
{
    // ... 之前的配置
    "plugin": {
        "ExportMesen2Label": {
            "output": "[name]_temp.json"
        }
    }
}
```

主要设置方法是在 `plugin` 内加入插件的配置，比如 `ExportMesen2Label`，则在 `plugin` 内加入插件名称 `ExportMesen2Label`。

其次在 `ExportMesen2Label` 内加入配置，则在 `ExportMesen2Label` 内加入配置即可。

## 内置插件

### ExportMesen2Label

该插件在编译完成后，将标签导出到一个所有全局标签到 JSON 文件中。

配置:

```json
{
    "output": "[name]_temp.json",  // 可输出文件路径，例如: "label.json" "[name].json"
    "labelExclude": [],            // 要排除的标签名称的正则表达式
    "fileExclude": []              // 要排除的文件路径的正则表达式
}
```
